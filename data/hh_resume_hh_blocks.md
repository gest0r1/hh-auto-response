### 1. FPV40 Campus — LMS-платформа для FPV-пилотов
**Компания:** Собственные проекты / Частная практика
**Должность:** Python Backend / Full-stack Developer / Tech Lead
**Период:** 2025 - май 2026

Полноценная LMS-платформа с микросервисной архитектурой для онлайн-обучения управлению FPV-дронами. 16 модулей, 134+ урока, 30+ интерактивных React-компонентов, система прогресса, сертификаты, биллинг через ЮКассу.

Ключевые достижения:
- 4 микросервиса: auth (JWT/RBAC/Google OAuth), core (модули/квизы/прогресс/XP), media (MinIO/S3), Telegram-мониторинг
- 30+ кастомных интерактивных React-компонентов: DroneDiagram, BetaflightMap, PidTuningViz, LipoChargeViz и др.
- Платёжная система ЮКасса: тарифы «Пилот Старт» (9 900 ₽) и «Пилот Про» (19 900 ₽), webhook-обработка
- Генерация сертификатов с гильошированной рамкой, герб РФ, кастомный CSS-overlay
- CI/CD: GitHub Actions (develop→dev, main→prod), 7 Docker-контейнеров, автобэкап БД
